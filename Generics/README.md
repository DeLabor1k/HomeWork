#firstTask
Что делает этот код?:
Это очередь, где элементы достаются не в порядке добавления, а по приоритету
Самый важный (с большим числом) достаётся первым

Как это работает?

<T> - уголковые скобки означают, что класс может работать с любым типом данных (числа, строки, объекты)
_prioritySelector - это функция, которая для любого элемента вычисляет его приоритет (число)
_items - список, где хранятся тройки значений:
item - сам элемент
priority - его приоритет (число)
order - номер по порядку добавления (0, 1, 2...)
_orderCounter - счётчик, который увеличивается при каждом добавлении
Enqueue - метод добавления:
Вычисляет приоритет элемента через функцию
Сохраняет элемент в список вместе с его приоритетом и номером
Dequeue - метод извлечения:
Проверяет, есть ли элементы
Перебирает все элементы, ищет элемент с наибольшим приоритетом
Если приоритеты равны, выбирает тот, у которого меньше order (добавлен раньше)
Удаляет найденный элемент и возвращает его
Peek - показывает первый элемент без удаления (работает так же, как Dequeue)
Count и IsEmpty - простые свойства для получения информации об очереди
Почему order так важен?
Без order при равных приоритетах может быть выбран любой элемент
order гарантирует, что элементы с одинаковым приоритетом будут доставаться в порядке очереди (FIFO)
