# firstTaskPriorityQueue<T>

## Описание

Обобщённая очередь, где элементы извлекаются в порядке убывания приоритета. Приоритет вычисляется функцией `Func<T, int>`, передаваемой в конструктор. При равных приоритетах сохраняется порядок добавления (FIFO).

## Поля класса

| Поле | Тип | Назначение |
|------|-----|------------|
| `_prioritySelector` | `Func<T, int>` | Функция вычисления приоритета элемента |
| `_items` | `List<(T, int, int)>` | Список кортежей (элемент, приоритет, порядок добавления) |
| `_orderCounter` | `int` | Счётчик порядка добавления элементов |

## Методы

### PriorityQueue(Func<T, int> prioritySelector)
Конструктор. Инициализирует пустую очередь и счётчик.

### void Enqueue(T item)
Добавляет элемент. Вычисляет его приоритет, сохраняет вместе с текущим порядковым номером, увеличивает счётчик.

### T Dequeue()
Извлекает элемент с наибольшим приоритетом. При равных приоритетах выбирает добавленный раньше. Удаляет его из очереди и возвращает. Если очередь пуста - выбрасывает `InvalidOperationException`.

### T Peek()
Возвращает элемент с наибольшим приоритетом без удаления. При равных приоритетах возвращает добавленный раньше. Если очередь пуста - выбрасывает `InvalidOperationException`.

### int Count
Свойство. Возвращает количество элементов в очереди.

### bool IsEmpty
Свойство. Возвращает `true`, если очередь пуста.

## Алгоритм

- **Enqueue:** O(1) - добавление в конец списка
- **Dequeue/Peek:** O(n) - линейный поиск максимального элемента
- **Стабильность:** Гарантируется полем `order` - элементы с равным приоритетом извлекаются в порядке добавления
